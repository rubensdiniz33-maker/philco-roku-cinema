# TV

A cinematic Roku channel interface prototype built with BrightScript and SceneGraph.

- Redesigned TV home screen with minimal branding and fewer labels
- Left/right remote navigation and OK selection feedback
- Demonstration titles only: no streaming playback or third-party app launching is implemented
- Runs as a separate Roku channel and does not replace the Roku OS home screen

Target test device: Philco PTV32G7PR2CSBLH, Roku OS 15.3.
