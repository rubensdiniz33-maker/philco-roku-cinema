# Philco Roku Cinema

A cinematic streaming-style home-screen prototype for Roku, built with BrightScript and SceneGraph.

## Current prototype
- Dark cinematic interface with red accents
- Hero area and horizontal selection row
- Roku remote left/right navigation and OK selection feedback
- Demonstration cards only: this prototype does not stream content or launch third-party services

## Target device
Philco PTV32G7PR2CSBLH, Roku OS 15.3 (HD UI).

## Development
The project is packaged as a Roku channel ZIP and installed through the Roku developer installer on the local network. The channel runs separately from Roku OS and does not replace the native home screen.
